Accessible Restroom in Bangladesh — starter app

Files:
- index.html: the working mobile-friendly app
- manifest.webmanifest: install metadata

Important:
This starter is based only on the places visible in your screenshots (9 entries), not all 25 places in the original Google Maps list.
The app can search, filter accessible entries, open Google Maps searches, and remember visited places on the same browser/device.

To install as a true home-screen web app:
1. Host these files on an HTTPS static host (for example GitHub Pages or Netlify).
2. Open the hosted HTTPS address in Chrome on Android.
3. Tap ⋮ > Add to Home screen (or Install app).

Opening index.html directly works as a webpage, but may not offer full PWA installation while offline/local.
